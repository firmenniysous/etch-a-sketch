# etch-a-sketch

A simple Etch-a-Sketch project built with HTML, CSS, and JavaScript.

### Features

* Draw by hovering over the grid
* Change the grid size
* Reset the canvas
* Simple and responsive interface

This project was created as part of my JavaScript practice.
